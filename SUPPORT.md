# Support

## Where to ask questions

- **GitHub Discussions** on the relevant repository — preferred for how-to questions and ideas (categories: Q&A, Ideas, Announcements).
- **Docs and product info:** [kestrellabs.org](https://kestrellabs.org)

## What not to use issues for

Please use Discussions (or email below) for support questions. GitHub Issues are for confirmed bugs and actionable feature work.

## Security

Report vulnerabilities to **security@kestrellabs.org** — see [SECURITY.md](./SECURITY.md).
