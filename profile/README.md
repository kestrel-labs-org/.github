# Kestrel Labs

Kestrel Labs builds free, open-source tools for **Linux** — an app store client, backup, and a WireGuard-compatible VPN — with an optional cloud service when you want sync, enrollment, or managed backup.

We aim to support Linux broadly; **we're starting with Debian-based distros and variants** (`.deb` packaging first), then expanding from there.

Everything you install from us is **GPLv3 (or later)**. [kestrellabs.cloud](https://kestrellabs.cloud) is the optional paid service; the clients stay open either way.

## Public projects

| Project | What it is |
|---|---|
| **[kestrel-app-manager](https://github.com/kestrel-labs-org/kestrel-app-manager)** | Linux app store client (app sync + org enrollment); Debian-based first |
| **[kestrel-backup](https://github.com/kestrel-labs-org/kestrel-backup)** | Backup client (restic-based); Linux first, more platforms later |
| **[wgclient](https://github.com/kestrel-labs-org/wgclient)** | WireGuard-compatible VPN client for Linux desktops (community) |
| **[kestrel-catalog](https://github.com/kestrel-labs-org/kestrel-catalog)** | Community app listings for the store (CC0) |
| **[kestrel-brand](https://github.com/kestrel-labs-org/kestrel-brand)** | Logos, palette, and trademark policy |
