# Kestrel Labs

Kestrel Labs builds free, open-source tools for Kubuntu/KDE — an app store client, backup, and a WireGuard-compatible VPN — with an optional cloud service when you want sync, enrollment, or managed backup.

Everything you install from us is **GPLv3 (or later)**. [kestrellabs.cloud](https://kestrellabs.cloud) is the optional paid service; the clients stay open either way.

## Public projects

| Project | What it is |
|---|---|
| **[kestrel-app-manager](https://github.com/kestrel-labs-org/kestrel-app-manager)** | Store client for Kubuntu/KDE (app sync + org enrollment) |
| **[kestrel-backup](https://github.com/kestrel-labs-org/kestrel-backup)** | Cross-platform backup client (restic-based) |
| **[wgclient](https://github.com/kestrel-labs-org/wgclient)** | WireGuard-compatible VPN client for KDE (community) |
| **[kestrel-cloud](https://github.com/kestrel-labs-org/kestrel-cloud)** | Shared Python client library for auth, device login, and sync |
| **[kestrel-catalog](https://github.com/kestrel-labs-org/kestrel-catalog)** | Community app listings for the store (CC0) |
| **[kestrel-brand](https://github.com/kestrel-labs-org/kestrel-brand)** | Logos, palette, and trademark policy |
